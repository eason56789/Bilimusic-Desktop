# BiliMusic 宣传片 · Apple 风格分镜脚本

配乐:《苹果进行曲》《大米的小曲》-【Hi-Res无损】《3 strikes》
来源:https://b23.tv/fq9ETTU (BV1RqYzzKEUd,Nichi的唱片机)
时长:2:56(176 秒)| 单曲循环结构:三段推进 + 一次静默重置

---

## 定情绪场景

深夜的书桌。屏幕是唯一的光源。一个不想被打扰的人,想听一首真正属于自己的歌。
不是"音乐 App 很好用",而是"这一刻,世界安静了"。

## 核心主张(一句话)

**把歌找回来,把界面藏起来。**

## 产品三步语法

1. 主视图揭幕 —— 黑色中亮起一行歌词
2. 细节/材质/功能 —— 逐字上色、分层模糊、跨平台音源
3. 真实场景 —— 深夜、通勤、写代码的人

## 声音设计

| 段落 | 处理 |
|---|---|
| 0:00–0:14 | 只留前奏,音量 −12dB,刻意"听不清" |
| 0:14 起 | 主歌进入,音量正常 |
| 1:00 副歌 | 全力,不加任何音效,避免抢戏 |
| 1:12 起 | 每段回落 −4dB,给旁白留位置 |
| 2:22 起 | 只剩尾韵,最后 10 秒完全静默 |
| 全程 | 旁白总计 5 句,约 40 字。任何一句删掉都不影响理解 |

## 视觉规范

- **灯光**:每镜都有柔背光勾轮廓;屏幕/机身保持 45° 反光,不做正面平光
- **构图**:中心构图为主;文字镜头保留下三分之一;产品镜头四周留白 ≥ 30%
- **调色**:不套统一滤镜。0:00–1:00 冷灰低饱和;1:00–1:12 提对比;1:12 之后回中性
- **文字**:逐字上色只用金 `#ffd54a` / 冷蓝 `#4d9fff` 两色,不引入第三种

## 自检

- [x] 每镜只有一个想法(15 镜,每镜一个功能或一个情绪)
- [x] 展示而非告知:逐字上色、自动变宽、三平台并列全部用画面证明
- [x] 有停顿与留白:01 镜 7 秒静止、06 镜 build-up 不动镜头、15 镜 18 秒黑场
- [x] 旁白可删:5 句共 40 字,删掉后画面仍成立
- [x] 产品被认真凝视:11、12 镜给足时长与留白,不做快速剪辑
